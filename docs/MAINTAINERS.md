# Maintainers & Governance

This file documents the suggested maintainers, release owners, and contacts for security issues. Adjust as appropriate for your organization.

## Roles

- Core Maintainers: review PRs, approve releases, triage issues.
- Release Manager: performs releases, manages GitHub Releases and external artifacts.
- Security Contact: receives vulnerability reports privately.

## Suggested process

- Use GitHub Issues and Pull Requests for all changes.
- Require at least one reviewer for non-trivial changes.
- Use semantic versioning for releases.
